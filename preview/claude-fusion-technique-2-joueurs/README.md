# Fusion Fighters

Jeu de combat 3D dans le navigateur : le Tourbillon contre 100 adversaires classés, créateur d'adversaires (419 techniques), mode test, vidéos d'apprentissage.

## GitHub Pages

- `main` → https://adrien426.github.io/Fusion-Fighters/
- toute autre branche → https://adrien426.github.io/Fusion-Fighters/preview/<branche>/

La publication est faite par `.github/workflows/pages-preview.yml` sur la branche `gh-pages`.
Activer Pages : Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`.
